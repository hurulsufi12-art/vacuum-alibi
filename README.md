# The Vacuum's Alibi: One Line, 200 Characters

One line (≤200 characters): the excuse a robot vacuum gives for missing a spot.

> Log 04:12: spot detected, spot evaluated, spot declared part of the rug. Removing it would have been vandalism.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
